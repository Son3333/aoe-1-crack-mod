# ⚔️ AOE 1: RISE OF ROME - BẢN MOD MENU PRO (RAM ENGINE)

Bản cài đặt chuẩn **Age of Empires 1: Rise of Rome** đã được tích hợp sẵn No-CD và bộ công cụ **Mod Menu Pro (RAM Trainer)** can thiệp trực tiếp bộ nhớ, thao tác 1 chạm siêu tốc 0.0001 giây, không giật lag và không văng game.

---

## 🚀 HƯỚNG DẪN KHỞI CHẠY (1-CLICK RUN)

1. Tải về và giải nén thư mục (hoàn toàn **không cần mật khẩu**).
2. Nhấp đúp vào file:
   👉 **`CHAY_GAME_VA_MOD.bat`**
3. Trình khởi chạy sẽ tự động:
   - Kiểm tra môi trường Python của máy bạn.
   - **Tự động cài đặt** các thư viện cần thiết (`psutil`, `keyboard`) nếu máy chưa có.
   - Khởi chạy đồng thời **Game Age of Empires** và **Mod Menu Pro**.

*(Nếu chỉ muốn mở riêng Mod Menu khi game đã bật sẵn, bạn chỉ việc nhấp đúp chạy file `mod_menu.py`)*
